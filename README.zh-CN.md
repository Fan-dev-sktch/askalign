# AskAlign：Codex 对话内问答卡片

**AskAlign／问齐**：通过提问对齐真实需求。旧称 Grill Me，现侧重多轮需求访谈、场景检验与实施前确认。旧插件 ID、`grill_me_*` 工具名、技能目录和偏好路径暂保留兼容；已有用户沿用原安装。上游来源声明保留在 NOTICE 与 LICENSE 中。

维护者标识：**Fan-dev-sktch**。详见[作者与上游来源](NOTICE.md)、[下载校验与来源说明](docs/AUTHENTICITY.md)。公开主仓库：https://github.com/Fan-dev-sktch/askalign ；发布包附带 SHA-256 校验值和文件清单，校验不等于数字签名。

## 提问强度与提交摘要

支持少问、适度确认、深入探索三档；可分别调整覆盖范围、深度和频率，保存默认偏好或仅作用于本次任务。安装附带 skill 后，助手在澄清前读取设置。工具返回策略指令，实际提问质量仍需用真实任务验证。

提交后保留紧凑答案摘要，可原位展开查看，不主动关闭宿主卡片。详见 [设置与卸载](docs/SETTINGS.md)、[隐私与存储](docs/PRIVACY.md)。

`npm run release` 生成只含发布文件的源码包，排除个人配置、备份、依赖和历史卡片版本。正式 UI 入口为 `server/decision-v8.html`。

[English](README.md) · [在线体验卡片](https://fan-dev-sktch.github.io/askalign/docs/demo.html) · [下载测试版](https://github.com/Fan-dev-sktch/askalign/releases)

稍复杂任务先核对目标，只有你的回答会改变成果时才弹卡。在对话里一次问清一个决定：单选后自动切换下一题，多选完成后点“下一题”，随时返回修改；“其他”直接在选项内部填写。最后一题答完自动交回对话，继续工作。

## 安装

需要 Node.js 22.12 或更高版本，以及支持 `codex mcp add` 的 Codex CLI。卡片还要求宿主支持 MCP Apps；纯文本客户端会使用文字回退。

把仓库下载到固定目录，然后在该目录执行：

```sh
npm ci
npm run configure
npm test
```

`configure` 根据本机路径生成 `.mcp.json`，并输出可直接复制的注册命令。执行该命令后，将 `skills/grill-me` 文件夹复制到个人 `~/.agents/skills/` 中（Windows 对应用户目录下的 `.agents/skills`）。已有同名技能时先保留原文件，再决定是否替换。开启新 Codex 任务，使新工具和技能被发现。

已经通过插件方式安装 AskAlign 的用户，应更新原插件，避免重复注册服务器。GitHub 开源与官方插件目录上架是两件事。

## 使用

可以说：“用 AskAlign 问清这个项目接下来最关键的选择。一次只显示一道题，不依赖答案的工作继续做。”

模型应该把已知、独立的问题放进同一组卡片；上一组尚未回答时，不再创建新的待答卡片。单组卡片内始终只显示当前问题。旧工具调用仍会留在宿主的聊天历史中，插件不能替宿主删除它们。

插件自身不调用模型、不需要 API Key，也不发送遥测；仍使用宿主原有的模型额度。支持中文、英文控件及自填答案。收到回答后是否继续工作，取决于宿主能否接收后续消息。

## 当前边界

- 实际宽度、显示位置和宿主中的蓝色细节，需要在对应客户端验收。
- 当前卡片提交后会禁用；跨刷新恢复需要宿主提供状态保存，不能承诺所有客户端都能绝对防重。
- 若发送超时，结果可能已到达对话，因此不自动重发。
- 提问技能能改善模型提问方式，但不能保证每个问题都恰好问到用户真实需求。
