# 说透 · SpellOut

**点几下，把想法说透，AI 再动手。**

[English](README.md) · [第一次使用：体验、安装与排错](docs/QUICKSTART.zh-CN.md) · [提问设置](docs/SETTINGS.md)

不必一开始就写完整需求。先说一个想法，让 AI 用点选、自由补充和逐轮追问，确认你要解决什么、在意什么、怎样才算完成。每轮可设 1 到 5 题，一次显示一道；适度确认和深入探索默认每轮最多 3 题，可自行调到 5 题。

交互灵感来自 Claude Code 的提问卡片。本项目与 OpenAI、Anthropic 无关。提问质量依赖模型执行，不能保证每次充分理解，也不是宿主层面的执行锁。

## 先体验，再安装

**体验最新改进：在本仓库选择 main 分支 → Code → Download ZIP。** 已发布的预览包仍在右侧 Releases → v0.5.0 → Assets → `spellout-source.tgz`，不包含下述后续改进。两者均为源码，不是应用商店的一键安装包。

在包含 `package.json` 的源码目录运行 `npm run demo`，打开终端打印的地址，即可尝试单选、多选和自由补充。只需要 Node.js，无需先安装插件或登录账号；演示不运行 AI，不修改设置。这个命令已加入 main 分支，尚未包含在已发布的 v0.5.0 中。GitHub 上的[演示源码](docs/demo.html)本身不能直接点击体验。

第一次使用可按[三步指南](docs/QUICKSTART.zh-CN.md)完成：**下载到固定目录 → 检查并安装 → 在新对话中提交第一张卡**。指南包含前置工具、解压位置、可复制的体验提示词和故障对照表。

## 安装

**0.5.0 是不兼容更新。** 先阅读[迁移说明](docs/RELEASE.md)，手动移除旧安装。安装前确认解压包的版本号为 0.5.0。

需要 Node.js 22.12+、Codex CLI 和支持 MCP Apps 的客户端。把源码解压到固定目录，在含有 `package.json` 的目录打开终端：

```sh
npm run doctor
npm run setup
```

前一条只检查，后一条经确认执行安装。不需要提前运行 npm install。

向导先检查，再经确认安装依赖、运行测试、注册 MCP 和安装技能。检测到旧安装会停止并给出手动指引，不自动删除。向导安装且未被改动的技能可升级：先复制到 `~/.agents/skill-backups/` 中带版本号的备份目录并校验，再安装新版，避免备份被重复识别为技能。用户改动过的文件会阻止升级。

`npm run doctor` 只检查，显示已装技能版本、仓库版本及是否一致。重开客户端后，用“请用 SpellOut 帮我问清需求”测试卡片和回答读取。

## 操作与设置

- 可同时成立的需求用多选；互斥决定或确需唯一优先项时用单选。单选后进入下一题，多选后确认；“其他”可直接写，提交前可返回。
- 小箭头展开设置和需求摘要；提交后收起为“待读取”，答案确认处理后显示“已完成”。这里表示本次问答完成，不代表项目已实施完毕。
- 少问、适度确认、深入探索三个档位，另有覆盖、深度、频率、多样性、质疑程度和每轮题数设置。
- 新用户默认深入探索；第一次需要澄清时先用设置卡选择提问方式，明确保存后用于同一安装的后续对话。已有偏好保持不变。简单问题、已明确的指令不必发卡；全局安装提供各对话发现技能的入口，不保证模型每轮调用。详见[首次设置](docs/SETTINGS.md)。
- 明确要求多轮访谈时，普通答案仅表示继续访谈，需求总结需确认后再实施。
- 答案保存并读取，不自动追加消息。最新已确认答案标记为已处理，避免上下文压缩后重复执行。
- 超时显示保存未确认并立即核对；保存本身不能唤醒已结束的回合。

## 验收与隐私

**真实 Codex 界面：未验收；手机 Remote：未验收。** 本地 DOM 与接口测试不代表手机可见。卡片不可用时提供普通文字编号选项。演示页只有预设问题，不运行 AI。

插件不额外调用模型或发送遥测。偏好和记录保存在本机；`npm run forget` 默认仅预览，删除须明确指定年龄和 `--yes`。详见[隐私与清理](docs/PRIVACY.md)。

`npm run release` 仅构建本地源码包，不上传。源码包包含 `server/card.html`，不含打包历史 HTML 快照。MIT 许可与来源见 [LICENSE](LICENSE)、[NOTICE](NOTICE.md)。维护者：[Fan-dev-sktch](https://github.com/Fan-dev-sktch)。

## main 分支的后续改进（尚未发布新版安装包）

- 点开小箭头即可看到全部提问设置；新增每话题追问上限、覆盖方面数和候选数量。
- “帮我想清楚”提供举例、比较、都不合适的可编辑请求，随本轮答案提交。
- 需求单可编辑目标、要求、限制、验收条件和未知项，并复制到其他对话；未保存草稿有明确标记。
- 自检状态可以先查看再复制，不自动发送，也不包含问题和答案正文。
- 技能升级备份保存在 `~/.agents/skill-backups/`，避免备份也被识别为技能；doctor 会报告技能扫描目录里遗留的备份。
- 普通实施任务选定范围后直接开始；只有明确要求先访谈时，才等待访谈总结确认。
