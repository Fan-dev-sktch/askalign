# 问齐 · AskAlign

## 点一点，把真正想做的事聊清楚。

不用一开始就写出完整需求。先说一个想法，让 AI 通过问题帮你逐步想清楚：你想解决什么、在意什么、最后希望做成什么。

AskAlign 为 Codex 提供问答卡片和提问引导。能点选就少打字，选项不合适就直接补充；需要深入时，继续追问，再确认是否开始做。

[在线体验卡片](https://fan-dev-sktch.github.io/askalign/docs/demo.html) · [下载安装](#开始使用) · [English](README.md)

**0.4 测试版 · 需要 Node.js 22.12+、Codex CLI 和支持 MCP Apps 的客户端。** 在线演示使用预设问题，不运行 AI。

## 顺手，具体在哪里？

- **一次只看一道题。** 单选后进入下一题；多项都重要时可以多选。
- **想补充，直接写。** “其他”里就能填写，回车继续；提交前可以返回修改。
- **问多问少，由你决定。** 少问、适度确认、深入探索三个档位；复杂项目还可以要求多轮访谈、场景检验和总结确认。

不熟悉提示词，也可以从自己的日常表达开始。提问引导仍依赖模型执行，不能保证每次都问到关键点或自动完成全部目标。

## 比如，你只知道“想做一个反馈页面”

可以这样开始：

> 我想做一个反馈页面，但还没想清楚需要哪些功能。先和我多轮问答，确认需求后再开始做。

后续可以逐步确认：给谁用、是否匿名、是否需要登录。你点选或补充自己的答案，再检查总结是否符合预期。这是使用示例，不是固定问卷或真实用户效果统计。

## 开始使用

[下载测试版](https://github.com/Fan-dev-sktch/askalign/releases)，解压到固定目录，在该目录打开终端，运行：

```sh
npm run setup
```

向导会检查环境和已有安装。确认计划后，安装依赖、运行检查、注册缺失的 MCP 并复制技能；已有插件或文件冲突会提示处理，不自动覆盖。

完成后重新打开 Codex、新建任务，粘贴向导给出的体验口令。看到卡片、完成选择、确认助手准确读回答案，才算在你的客户端走通。

只想检查安装状态，运行 `npm run doctor`。手动安装、重复注册和卸载说明见 [设置与维护](docs/SETTINGS.md) 及 [英文安装说明](README.md#install-locally)。

## 兼容与隐私

当前版本经过本地 Windows 测试；跨系统 CI 和完整客户端验收仍未完成。网页卡片显示及回传取决于宿主支持，手机 Remote 图形卡片尚未验证。详见 [验收记录](docs/RELEASE.md)。

插件自身不额外调用模型、不要求单独的模型 API Key、不发送遥测；宿主原有额度照常使用。问题与答案保存在本机，详见 [隐私说明](docs/PRIVACY.md)。
