# 第一次使用说透

[English](QUICKSTART.md) · [返回首页](../README.zh-CN.md)

目标：成功看到一张卡，提交选择，并让 AI 准确复述答案。先完成这一轮，再调整更多参数。

## 先体验，不安装插件

本地演示需要 Node.js 22.12+，不需要 Codex、账号或模型额度。在含有 package.json 的源码目录打开终端，运行：

```sh
npm run demo
```

打开终端打印的浏览器地址，在 Language 中选择简体中文。完成单选、多选或自由补充后，下方会显示提交结果；“重新体验”清空本页答案。保持终端开启，结束时按 Ctrl+C。

**这个入口已加入 main 分支，尚未包含在已发布的 v0.5.0 包中。** 如果提示 Missing script: demo，说明正在用较早的包；体验新版请下载 main 源码，不必重复安装依赖。GitHub 上点开 demo.html 只会看到源码，不能直接操作卡片。演示只模拟界面，不运行 AI，也不验证真实客户端兼容性。

## 三步安装并验证

### 1. 下载到固定位置

体验最新改进：在本仓库选择 **main → Code → Download ZIP**。这是尚未打新版标签的源码，包含演示入口和新的上手改进。

如需已发布的预览包，在右侧 **Releases → v0.5.0 → Assets** 下载 `spellout-source.tgz`；需要校验时同时下载 `SHA256SUMS`，方法见[完整性说明](AUTHENTICITY.md)。该旧包不包含 main 的后续改进，校验文件也不能用于 main ZIP。

解压到以后不会移动的文件夹，例如 Windows 的 `C:\Tools\SpellOut`。找到同时含有 `package.json`、`server`、`skills` 的那一层，在这一层打开终端；不要直接在压缩包里运行，也不要安装后移动文件夹。

先确认安装了 [Node.js](https://nodejs.org/) 22.12+、[Codex CLI](https://learn.chatgpt.com/docs/cli) 和支持 MCP Apps 的客户端。可分别输入 `node --version`、`npm --version`、`codex --version` 查看。使用较旧版本升级时，先读[迁移说明](RELEASE.md)，保留个人偏好和答案数据。

### 2. 检查，再安装

```sh
npm run doctor
npm run setup
```

doctor 只检查，不会安装。新用户看到尚未安装技能或版本未知是正常的；若报告旧安装、冲突或缺少环境，按提示解决后再继续。

setup 会先列出将执行的步骤，经终端确认后安装依赖、运行测试、注册连接并安装技能。正常流程不需要提前运行 npm install。已有插件安装应更新原插件，避免重复注册；向导提示冲突时不要删掉答案数据来绕过。

### 3. 在真实对话里验证

重新打开客户端，新建一个任务，粘贴：

> 请用 SpellOut 帮我确认一个个人学习计划的需求，先不要制定计划。给我一张卡片，询问我的学习目标；收到答案后准确复述。

首次使用可能先出现提问方式设置卡。选定并保存偏好后，再进入学习目标问题。已有偏好不必重新设置。

成功要同时满足：

- 看到了实际卡片，能选选项或输入自己的答案。
- 提交后收起为“待读取”，AI 读取后显示“已完成”。
- AI 的复述包含你实际选的内容和自由补充；“已完成”只表示问答处理完成。

安装命令成功、演示能点击，都不能替代这三个检查。真实 Codex 桌面和手机 Remote 的兼容性仍需分别验证；手机看不到时直接用文字继续，不要求重复点隐藏卡片。

## 卡在哪里，就看哪一行

| 现象 | 下一步 |
|---|---|
| 找不到 package.json | 在解压后的项目根目录打开终端，不在上一层或压缩包内运行 |
| node、npm 或 codex 不是可用命令 | 安装缺少的前置工具，重新打开终端；Windows 如阻止 npm.ps1，可使用 npm.cmd |
| 发现旧安装或内容冲突 | 保留修改与用户记录，按向导及迁移说明处理；不要反复新增连接 |
| 演示地址打不开 | 保持运行演示的终端开启，使用本次打印的地址，端口每次可能不同 |
| 客户端内没有卡片 | 先运行 doctor，再重开客户端并明确提到 SpellOut；仍不可见时用文字选项，记录客户端与版本 |
| 已提交但没有回应 | 在对话中告诉 AI“请读取刚才那张卡的答案”；本地保存不能重新启动已结束的 AI 回合 |
| 仍提示保存未确认 | 保留原卡和输入，先让 AI 核对原卡状态；不要重复创建新卡。能打开自检时先检查状态 |
