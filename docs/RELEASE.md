# SpellOut 0.5.0 — 不兼容更新

点几下，把想法说透，AI 再动手。

Spell out your idea before AI builds it.

## 本版改动

- 显示名统一为 SpellOut · 说透，技术标识使用 spellout。
- 每轮题数上限可设为 1–5；原有偏好与档位默认值保持不变。
- 设置入口缩为小箭头，收起不单独占一行；答案回执只显示“待读取”或“已完成”。
- 兼容需求优先多选，修正技能中强制互斥的冲突规则；实际题型仍取决于模型调用。
- 首次使用引导、任务设置与长期默认分离；答案确认标记防止重复处理。
- 修复演示页提交、保存超时核对和临时文件清理，支持受管理技能升级和记录清理预览。

## 尚未包含

- 展开后显示全部参数、进一步把参数改成有明确含义的数字控制。
- 专门的“帮我想清楚”入口和场景示例引导界面。
- 手机 Remote 显示与最新版完整客户端体验的验收。

## 升级须知

- 旧对话里的卡片会失效：仅提供 `spellout_*` 工具和 `ui://spellout/card-<hash>.html` 资源，不再注册旧名称别名或打包历史页面。
- 需要先手动移除旧安装，再运行向导。检测冲突只打印指引，不自动删除注册或技能。
- 偏好会自动复制一次：新默认目录没有 preferences.json 时，只复制旧默认目录的这一个文件。旧答案、上下文不迁移，旧目录不移动、不删除。自定义设置路径不自动迁移。
- 新设置目录为 `~/.config/spellout/`，环境变量统一为 `SPELLOUT_*`。旧目录处理见 PRIVACY.md。

## 本地验证

1. `npm ci`，然后 `npm test`。
2. `npm run release` 生成本地源码包与 SHA256SUMS。
3. 解压至临时目录，运行包内 `node scripts/verify-release.mjs`。
4. 在隔离 HOME 和受控安装清单中分别执行新安装、旧安装的 `setup --check`。检查不得写入 Codex 配置或安装技能。
5. 在真实客户端加载后，单独验收显示、提交、恢复和手机入口。

白名单见 `scripts/release-files.mjs`，命名测试扫描其中全部文件。资源按内容哈希生成，新命名空间中的运行时缓存按原始字节读取；旧命名空间不兼容。

## 证据边界

自动测试与源码包校验不等于客户端验收。最新完整版本的真实 Codex 界面、手机显示和跨系统实际安装均为 **未验收**。预发布供试用反馈，不承诺所有宿主行为一致。
